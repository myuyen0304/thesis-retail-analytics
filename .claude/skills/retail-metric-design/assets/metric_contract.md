# Hợp đồng metric

Chỉ điền mục liên quan; ghi rõ trạng thái “đề xuất” hoặc “đã chốt”.

| Mục | Nội dung cần ghi |
|---|---|
| Câu hỏi và người sử dụng | Quyết định được hỗ trợ, PS liên quan |
| Metric | Tên tiếng Anh, nhãn tiếng Việt, đơn vị đã xác minh |
| Grain và khóa | Một dòng là gì; unique key của kết quả |
| Tập dữ liệu | Nguồn, trạng thái đơn, điều kiện loại/giữ |
| Thời gian | Trường ngày, kỳ đủ/thiếu, timezone nếu có timestamp |
| Công thức | Measure, distinct, tử/mẫu, quy tắc NULL/zero |
| Dimensions và bộ lọc | Những chiều cho phép, join cardinality, giới hạn cộng tính |
| Nguồn chuẩn | Model/SQL, phần tài liệu, notebook/cell chứng minh |
| Đối chứng | Nguồn độc lập, kỳ/nhóm kiểm, sai số được giải thích |
| Phạm vi suy luận | Quan sát, phân rã số học, giả thuyết chưa chứng minh |
| Nghiệm thu | Ca thông thường, biên, hồi quy và phần chưa kiểm |

Không dùng số đếm test hoặc KPI snapshot làm hằng số cho mọi nguồn tương lai.
